@lordicon/runtime

  • Playback: states, play, pause, loop, speed
  • Colours, stroke and tint: changed live, without reloading
  • Loops and events: a rest between rounds, tick()
  • Models: an icon parsed once for many, one clock for all, with timings
  • Workers: icons rendered on several threads, the main thread left free

Outside the browser:

  • examples/node/frames.mjs: frames of an icon to PNG files, in Node
  • examples/native/: the C API from a CMake project
